1. Select business scenario / 选择业务场景

先确认这份词表服务单市场还是多市场。平台据此推荐录入语种、翻译检查方式，以及审批通过后的本地语言撞库方式。

Required
Scenario A

Single-market quick config / 单市场快速配置

适合只服务一个目标市场的词表。录入侧可用本地语言，平台输出英语翻译结果用于 double check；执行侧使用该市场本地语言撞库。

Scenario B

Multi-market strategy reuse / 多市场策略复用

适合一份策略复用多个市场。业务可选择多种录入语言，英语作为默认归一语言；执行侧按目标市场语种匹配本地语言版本。

Input · 多语言录入与翻译检查

业务选择录入语种后，点击 Translate Agent。平台只展示各语种转化成功度，不展示逐词翻译；用户可导出结果或手动修改后提交审批。

Output · 审批后本地语言撞库

审批通过后词表进入 Active，被 IDSP 规则引用；执行时自动按来源语种 / 目标市场语种使用本地语言版本撞库。

3. After translation · export, edit, submit review / 翻译完成后处理

After Translate Agent finishes, users can export the result, manually edit low-confidence languages, or submit the word list for approval.
Review Path
Translation result not ready / 翻译结果未生成Click Translate first. Export, manual edit and review submission are enabled after translation finishes.
Review submitted / 已提交审批Demo decision: reviewer can approve or reject this submitted version.
Approval passed / 审批通过

Word list becomes Active. IDSP rules can reference the list, and runtime automatically uses local-language matching by source / target market language.

Approval rejected / 审批不通过

The submitted version is automatically saved as draft. Owner can reopen the draft later, edit the word list, and submit again.

Activation path after approval / 审批通过后的生效路径IDSP auto reads active version
Active

Rule Reference
